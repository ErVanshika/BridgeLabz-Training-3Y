```html Box Model Exploration
CSS Box Model Exploration

Every HTML element is treated as a box made up of content, padding, border, and margin.

MARGIN
BORDER
PADDING

CONTENT

This is the actual content area of the element.

Margin: Space outside the border
Border: Edge around the element
Padding: Space around content
Content: Actual text or elements

Default Box Model

Content Box

The default value is box-sizing: content-box. The width does not include padding and border.

Border Box Model

Border Box

With box-sizing: border-box, the declared width includes both padding and border.

```
