CSS Pseudo-Classes

Examples of hover, focus, active and nth-child pseudo-classes

:hover

The hover pseudo-class changes an element when the mouse pointer moves over it.

:focus

The focus pseudo-class applies styling when an input field is selected.

:active

The active pseudo-class applies styling while a button is being clicked.

The nth-child pseudo-class selects an element based on its position.
